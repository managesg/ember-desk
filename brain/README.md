# Company Brain notes

Put plain Markdown notes in this folder (decisions, who does what, prices, policies). Ember Council reads them and the advisors cite them as `brain/<file>.md Lx-y`.

- Use the **Company Brain** panel to add notes, approve notes the council proposes, and re-index.
- You can also edit the `.md` files by hand. Then press **Re-index**.
- This folder is ignored by git, so your company notes are never committed by accident.
- This README is not indexed.
